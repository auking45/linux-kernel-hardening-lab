📦 1. 슬랩 버퍼 경계 검증 (__check_heap_object)
`copy_to_user` 호출 시 SLUB 메타데이터(`s->usersize`, `s->useroffset`)를 조회하여, 요청된 복사 범위가 단일 할당 객체의 경계를 벗어나는지 검증함. 인접 객체 오버리드 방어.

📜 2. 커널 실행 코드 보호 (check_kernel_text_object)
커널의 실행 코드 영역(`[_stext, _etext]`)에서 유저 공간으로의 직접 복사를 엄격 차단함. 커널 함수 바이트코드 노출 및 ROP 가젯 주소 유출을 방어하여 KASLR 보호.
