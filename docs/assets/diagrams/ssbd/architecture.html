현대 슈퍼스칼라 CPU의 아웃오브오더(Out-of-Order) 실행 엔진은 선행 Store 명령어의 목적지 주소 계산이 지연될 때, 후행 Load 명령어와의 충돌 여부를 메모리 비모호화 예측기(Memory Disambiguator)를 통해 예측함. 예측기가 별칭(Aliasing)이 없다고 판단하면 Store 이전에 Load를 투기적으로 실행하여 지연시간을 줄이지만, 실제 주소가 일치할 경우 갱신 전의 Stale(이전 비밀) 데이터를 투기적으로 읽어 사이드 채널로 유출하는 취약점이 발생함.
