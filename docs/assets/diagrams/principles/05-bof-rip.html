정상 상태: 메모리 무결성 유지
▲ High Memory (상위 주소)
Return Address (LR / X30 / RET) 0x000000000040124a (<main+32>)
Saved Frame Pointer (FP / X29 / RBP) 0x7fffffffe050
stack_buffer[48..63] 0x0000000000000000
stack_buffer[16..47] 0x0000000000000000
stack_buffer[0..15] "NORMAL_DATA\0"
▼ Low Memory (하위 주소 - SP / RSP)
CPU 레지스터 및 명령어 흐름 (Dual Arch: AArch64 & x86_64)
Program Counter (PC / RIP) 0x401180 (<vulnerable_service>)
Stack Pointer (SP / RSP) 0x7fffffffe000
Frame Pointer (FP / X29 / RBP) 0x7fffffffe050
현재 실행 명령어:
memcpy(stack_buffer, user_input, 12);
💡 취약점 핵심: 입력 크기 검증 없이 메모리를 복사하면, 버퍼의 경계를 넘어 상위 주소에 위치한 SFP와 RET를 순차적으로 덮어쓰게 됨.
