📄 ELF 파일 구조와 이중 뷰 (Dual Views: Linking vs Execution)

⚙️ ELF 바이너리 구조 레이아웃 (ELF64)
ELF Header (Elf64_Ehdr, 64 Bytes) Magic: \x7fELF
Program Header Table (세그먼트 설계도) Execution View
• PT_LOAD 1 (Code Segment) R-E (.text, .init, .plt)
• PT_LOAD 2 (Read-Only Data) R-- (.rodata, .eh_frame)
• PT_LOAD 3 (Data/BSS Segment) RW- (.data, .bss, .got)
• PT_INTERP (/lib64/ld-linux-x86-64.so.2) Interpreter
• PT_GNU_STACK (스택 실행 권한 지정) RW- (NX/DEP)
Section Header Table (섹션 설계도) Linking View
