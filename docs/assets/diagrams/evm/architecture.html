🛡️ EVM (Extended Verification Module) Simulator Metadata HMAC Protection

확장 속성(xattr) 및 inode 메타데이터 위변조 방지, HMAC-SHA256 검증 및 권한 상승 차단

Enforce (Hardened)
⚡ EVM 복합 메타데이터 해시 검증 파이프라인 실시간 HMAC-SHA256 계산 및 거부 판정 추적

📊 EVM 런타임 지표

EVM 검증 모드: Enforce
인증 알고리즘: HMAC-SHA256
보호 대상 XATTR: ima, selinux, cap
총 검증 횟수: 0 회
메타데이터 위반 차단: 0 건

🔒 왜 IMA와 EVM이 함께 필요한가?

IMA는 파일 내용(Content)만 검사하므로, 공격자가 파일 본문을 건드리지 않고 security.capability를 조작(예: 일반 바이너리에 CAP_SETUID 부여)하거나 소유자(UID 0)를 바꾸면 루트 권한을 탈취당할 수 있음. EVM은 메타데이터 전체를 HMAC/전자서명으로 묶어 오프라인 변조를 원천 차단함.

📋 EVM 감사 및 무결성 이벤트
[init] EVM subsystem active. Key: encrypted master keyring
[policy] Protected xattrs: security.ima, security.selinux, security.capability
