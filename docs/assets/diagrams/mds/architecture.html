MDS & TAA Vulnerability Variants & Mitigation Matrix

취약점 명칭 (Variant) 공격 대상 마이크로아키텍처 버퍼 영향받는 CPU 아키텍처 하드웨어 완화책 리눅스 커널 완화책
MFBDS (ZombieLoad v1)
CVE-2018-12130		 Line Fill Buffer (LFB)
코어 간 데이터 로드/캐시 라인 필링		 Intel Sandy Bridge ~ Coffee Lake (x86_64) 마이크로코드 업데이트 (MD_CLEAR 지원) 커널-유저 공간 복귀 시 VERW 실행 + SMT 비활성화
MSBDS (Fallout)
CVE-2018-12126		 Store Buffer (SB)
스토어-로드 포워딩 주소 계산 지연		 Intel Haswell ~ Cascade Lake (x86_64) 마이크로코드 업데이트 (MD_CLEAR) VERW 버퍼 소거 + mds=full
MLPDS (RIDL)
CVE-2018-12127		 Load Ports (LP)
임시 로드 버퍼 레지스터		 Intel Nehalem ~ Whiskey Lake (x86_64) 마이크로코드 업데이트 (MD_CLEAR) VERW 버퍼 소거
TAA (ZombieLoad v2)
CVE-2019-11135		 TSX Transactional Abort 중 LFB 잔여 데이터 우회 Intel TSX 지원 프로세서 (Skylake, Cascade Lake) TSX 비활성화 (IA32_TSX_CTRL) / Microcode tsx_async_abort=full + VERW 버퍼 소거
MMIO Stale Data
CVE-2022-21123 등		 Device MMIO 읽기 버퍼 잔여 데이터 Intel 전반 (x86_64) 마이크로코드 버퍼 소거 기능 확장 mmio_stale_data=full (VERW 연동)
