🛡️ CONFIG_STRICT_KERNEL_RWX & W^X Memory Invariants

1. W^X 메모리 권한 모델 (표준)
CONFIG_STRICT_KERNEL_RWX: ACTIVE
리눅스 커널은 mark_readonly() 초기화 루틴을 통해 모든 메모리 페이지를 Write XOR Execute ($W \oplus X$) 원칙에 따라 분리합니다.

• .text (코드): $R-X$ (읽기/실행 가능, 수정 불가)
• .rodata (상수): $R--$ (읽기 전용, 실행 불가)
• .data/스택/힙: $RW-$ (읽기/쓰기 가능, 실행 불가)
하드웨어 통제 메커니즘:
• x86_64: CPU 레지스터 CR0.WP = 1 활성화로 커널 모드(Ring 0)에서도 RO 페이지 쓰기 금지.
• ARM64: 페이지 테이블 AP 속성 및 PXN/UXN 비트로 비실행 및 쓰기 통제.
