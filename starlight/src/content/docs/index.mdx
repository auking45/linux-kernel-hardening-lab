## 3. 11대 핵심 하드닝 카테고리 로드맵

| 카테고리 | 핵심 메커니즘 | 주요 Kconfig 및 기술 | 상태 |
| :--- | :--- | :--- | :---: |
| **01. Stack & Buffer** | 함수 스택 프레임 무결성 검증 및 버퍼 경계 검사 | `CONFIG_STACKPROTECTOR_STRONG`, `CONFIG_FORTIFY_SOURCE` | <Badge text="Ready" variant="success" /> |
| **02. Memory Layout** | 커널 텍스트, 모듈, 물리 메모리 배치 난수화 | `CONFIG_RANDOMIZE_BASE` (KASLR), FG-KASLR | <Badge text="Ready" variant="success" /> |
| **03. Memory Permissions** | W^X 메모리 보호, 유저/커널 영역 간 불법 실행·접근 차단 | `CONFIG_STRICT_KERNEL_RWX`, SMEP/SMAP, KPTI | <Badge text="Ready" variant="success" /> |
| **04. Control Flow Integrity** | 컴파일 타임 및 하드웨어 지원 간접 분기 추적 | Clang kCFI, Intel CET (IBT/SHSTK), ARM PAC/BTI | <Badge text="Ready" variant="success" /> |
| **05. Heap & SLAB Hardening** | 힙 메타데이터 난독화, UAF 방지 자동 영(0) 초기화 | `CONFIG_SLAB_FREELIST_HARDENED`, KFENCE | <Badge text="Ready" variant="success" /> |
| **06. Compiler Plugins** | 구조체 레이아웃 난수화, 스택 잔여 데이터 자동 소거 | `CONFIG_GCC_PLUGIN_RANDSTRUCT`, `STACKLEAK` | <Badge text="Ready" variant="success" /> |
| **07. Speculative Mitigations** | CPU 투기적 실행 결함(Spectre, Meltdown) 완화 | Retpoline, IBPB, STIBP, SSBD | <Badge text="Ready" variant="success" /> |
| **08. Access Control (LSM)** | 프로세스 단위 강제적 접근 통제 및 샌드박싱 | AppArmor, SELinux, Landlock | <Badge text="Ready" variant="success" /> |
| **09. Integrity Verification** | 파일 실행 무결성 해시 측정, xattr 서명, 정책 집행 | IMA, EVM, IPE, Kernel Lockdown | <Badge text="Ready" variant="success" /> |
| **10. Attack Surface Reduction** | 시스템 콜 필터링, 임의 메모리 접근 및 정보 누출 차단 | Seccomp-BPF, `CONFIG_STRICT_DEVMEM`, Yama | <Badge text="Ready" variant="success" /> |
| **11. Modern ARM & Mobile** | 하드웨어 메모리 태깅, 권한 오버레이, pKVM 및 기밀 컴퓨팅 | ARM64 MTE, ARMv9 POE, AVF / pKVM, Arm CCA | <Badge text="Ready" variant="success" /> |
