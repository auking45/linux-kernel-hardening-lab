## 1. 랩의 핵심 설계 철학 (Core Engineering Pillars)

<CardGrid stagger>
  <Card title="44+ 커널 하드닝 피처 전수 검증" icon="approve-check-circle">
    <Badge text="11 Categories" variant="tip" /> <Badge text="Kconfig + Source" variant="note" />
    
    단순 이론 요약을 넘어 Kconfig 정의, 컴파일러 플러그인, 커널 서브시스템 구현을 어셈블리 레벨까지 추적하고 Base 커널 vs Hardened 커널의 바이너리 차이를 실측 비교함.
  </Card>

  <Card title="x86_64 & ARM64 듀얼 아키텍처" icon="laptop">
    <Badge text="Intel CET / SMEP / SMAP" variant="note" /> <Badge text="ARM PAC / BTI / MTE" variant="caution" />
    
    인텔/AMD 하드웨어 보안 확장과 ARMv8/ARMv9 보안 확장 명령어가 동일한 공격 벡터를 각각 어떻게 가로채고 차단하는지 1:1 대칭으로 비교 실습함.
  </Card>

  <Card title="실전 Exploit PoC & LKDTM 증명" icon="warning">
    <Badge text="ROP / ret2usr / UAF" variant="danger" /> <Badge text="Runtime Panic Proof" variant="tip" />
    
    비권한 일반 사용자(`UID 1000`)에서 출발하는 실전 커널 익스플로잇 PoC와 LKDTM 크래시 주입을 통해 방어선의 정확한 절단 지점(Interception Point)을 런타임 로그로 증명함.
  </Card>

  <Card title="동적 제어 흐름 아키텍처 다이어그램" icon="puzzle">
    <Badge text="Zero-Scroll SVG" variant="success" /> <Badge text="Theme Synced" variant="note" />
    
    정적인 메모리 표에 그치지 않고, 공격 페이로드의 흐름과 MMU/카나리 가드의 실시간 차단 트랩을 인터랙티브 SVG 시뮬레이터로 직접 조작하며 탐색 가능함.
  </Card>
</CardGrid>
